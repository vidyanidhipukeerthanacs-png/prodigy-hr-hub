# Prodigy HR Hub

Create a modern, professional, and fully responsive Employee Management System web application for my Prodigy Infotech Task-02.

Project Requirements

Build a complete CRUD (Create, Read, Update, Delete) web application where administrators can manage employee records securely.

Authentication

Create a secure Admin Login and Signup page.

Use email and password authentication.

Passwords should be securely handled and validated.

Only logged-in administrators should access the dashboard.

Dashboard

Create a beautiful admin dashboard after login.

Display total employees, active employees, departments, and recent activities.

Add a modern sidebar with navigation: Dashboard, Employees, Add Employee, Reports, and Logout.

Employee CRUD Features

Add new employee records with fields:

Employee ID

Full Name

Email Address

Phone Number

Department

Job Role

Salary

Joining Date

Status (Active/Inactive)

Profile Photo (optional)

View all employees in a searchable and sortable table.

Update employee details through an edit form.

Delete employee records with a confirmation popup.

Add pagination for the employee table.

Validation & Security

Validate all form inputs before submission.

Prevent empty or invalid data.

Validate email and phone number formats.

Protect sensitive employee data with proper authentication and authorization.

Show success and error messages for all actions.

UI/UX Design

Use a clean and modern design with a purple/blue gradient theme similar to Prodigy Infotech branding.

Add smooth animations and hover effects.

Make the website mobile-friendly and responsive on all devices.

Use professional cards, buttons, icons, and tables.

Add a welcome message: Welcome to Employee Management System.

Extra Features

Add a search bar to find employees by name, ID, or department.

Add filters for department and employee status.

Include a profile page for each employee.

Add a dark/light mode toggle.

Add a logout button with confirmation.

Include a footer with Prodigy Infotech Task-02.

Technology

Use HTML, CSS, and JavaScript for the frontend. If backend/database support is available, use Node.js with Express and MongoDB to store employee data permanently.

The final website should look like a real-world professional Employee Management System suitable for an internship project submission.
